# Full-Stack Booking Platform

A production-ready booking system built from scratch — 
JWT authentication, MongoDB persistence, REST API 
architecture, and a clean Tailwind UI frontend.

## Tech Stack
- **Frontend:** React.js, Tailwind CSS, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Auth:** JWT + Cookie Management
- **Testing:** Jest (full test suite)
- **Deployment:** Render + Vercel

## Features
- User authentication with JWT and secure cookies
- Full booking CRUD operations
- Email integration for confirmations
- REST API with proper error handling
- Complete Jest test suite coverage
- Environment-based config management

## Project Structure
src/          → Frontend React components
server/       → Node.js + Express backend
tests/        → Jest test suite
public/       → Static assets
